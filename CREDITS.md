# Credits

## Art
All sprites, tiles, props, UI and effects are original pixel art made for this game. They are generated by
`tools/make_art.mjs` from a fixed 30-color palette (`tools/palette.json`) and checked by `tools/check_palette.py`.
The art code was written with AI assistance (Claude Code). No image-generation tool or pasted image was used for any art.

The art pipeline (master palette, palette check script, preview and contact-sheet tools, flat stepped darkness) follows
the method of the Ashgrove project, which is the same author's. No Ashgrove art or code was copied.
